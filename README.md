# 🏷️ Modern Brand - Identity & E-commerce System

A professional Full-Stack authentication and user management system designed for a modern fashion brand. This project focuses on secure data handling, real-time user feedback, and a seamless registration experience.

---

## 🚀 Key Features

* **Secure Authentication:** Full registration flow using **JWT (JSON Web Tokens)** and **BcryptJS** for password hashing.
* **Smart Form Validation:** Robust client and server-side validation using **Zod** and **React Hook Form**.
* **Password Security:** Real-time password strength estimation powered by the **zxcvbn** library.
* **Stateful UI:** Interactive user experience with **React Hot Toast** notifications and loading states.
* **Session Persistence:** "Remember Me" functionality utilizing browser local storage.
* **Database Integration:** Scalable data modeling with **MongoDB** and **Mongoose**.

---

## 💻 Tech Stack

* **Frontend:** Next.js 15 (App Router), TypeScript, SCSS.
* **Backend:** Next.js API Routes (Serverless Functions).
* **Database:** MongoDB with Mongoose ODM.
* **Validation & Security:** Zod, BcryptJS, JWT, zxcvbn.
* **Styling:** SCSS & Tailwind CSS.

## 🛠️ Setup Instructions

1.  **Clone the Repo:**
    ```bash
    git clone [https://github.com/aml-abdelrhman/modern-brand-project.git]
    ```
2.  **Install Dependencies:**
    ```bash
    npm install
    ```
3.  **Environment Setup:**
    Create a `.env.local` file and add your credentials:
    ```env
    MONGODB_URI=your_mongodb_connection_string
    JWT_SECRET=your_secure_jwt_secret
    ```
4.  **Run Locally:**
    ```bash
    npm run dev
    ```
